# Алиса для VK Капсулы

Голосовой помощник с GPT, который работает параллельно с Марусей. Работает на капсуле, без внешних серверов на других устройствах. Для ответов GPT и озвучивания нужен интернет, распознавание речи выполняется локально.

## Установка по шагам

1. **Проверьте колонку.** Готовый установщик поддерживает большую VK Капсулу на Rockchip RK3308. Если у вас Мини, сначала прочитайте [инструкцию для Мини](docs/mini.md).

2. **Настройте Марусю.** Подключите её к Wi-Fi обычным способом через приложение, проверьте ответы и музыку. Алиса будет использовать то же подключение.

3. **Подключите большую Капсулу к компьютеру в режиме Recovery.** Отключите питание. Переверните колонку и аккуратно подденьте край нижней резиновой накладки; постепенно отделите её от основания. Разбирать корпус и откручивать винты не нужно. Под накладкой находится micro-USB и два маленьких отверстия с кнопками. **Recovery — кнопка в отверстии, которое ближе к центру основания.** Подключите micro-USB кабелем с передачей данных к компьютеру. Иглой аккуратно нажмите и удерживайте Recovery, подключите штатный провод питания, через 2–3 секунды отпустите кнопку. Дальше удерживать её не нужно.

   В Windows PowerShell проверьте, появилось ли USB-устройство:

   ```powershell
   Get-PnpDevice -PresentOnly | Where-Object InstanceId -match 'VID_2207&PID_330[DE]'
   ```

   Ожидается устройство с ID `2207:330D` или `2207:330E`. В этом режиме колонка ещё не является ADB-устройством. Если вывода нет, проверьте кабель и повторите подачу питания с зажатой Recovery.

4. **Скачайте [capsula-jb для вашей системы](https://github.com/librecapsula/capsula-jb/releases/latest)** и распакуйте архив. В Windows откройте PowerShell в распакованной папке. Инструмент получает root, добавляя системный оверлей; основная прошивка и Маруся сохраняются. Сначала выполните только резервное копирование:

   ```powershell
   .\capsula-jb.exe backup
   ```

   Дождитесь успешного завершения и сохраните полученную папку `backup` отдельно от программы. Не продолжайте при ошибках бэкапа.

   **Исключение — некоторые колонки первого поколения:** инструмент определяет их сам; полный бэкап на них невозможен, а получение root стирает userdata с настройками. В таком случае продолжайте только если согласны с потерей данных и отсутствием полного восстановления из бэкапа.

5. **Получите root.** В той же папке запустите:

   ```powershell
   .\capsula-jb.exe
   ```

   Следуйте сообщениям программы. Если она попросит снова подключить колонку в Loader, повторите шаг 3. Дождитесь обычной загрузки и ответа Маруси. Если после очистки настроек сеть потеряна, подключите её через штатное приложение.

6. **Скачайте [AliceForMarusia-Setup.exe из Releases](https://github.com/SergTyapkin/alice-for-marusia/releases/latest).** Это установщик помощника для Windows с ADB и необходимыми ARM64-компонентами. Python на компьютере не нужен. Модель слова «Алиса» он отдельно скачает из закреплённого upstream и проверит по SHA256.

7. **Запустите установщик с подключённой по USB колонкой.** Устройство должно быть в обычном режиме, без удержания кнопок. Если колонка одна, она выберется автоматически; если устройств несколько, установщик предложит список. Он проверит root, модель колонки, свободное место и контрольные суммы, затем установит помощника. Полную прошивку он не перезаписывает.

   Для запуска из консоли:

   ```powershell
   .\AliceForMarusia-Setup.exe
   ```

   `--serial` нужен только при явном выборе устройства. Это **точный идентификатор из `adb devices`**, например `0123456789ABCDEF`, а не номер COM-порта: ни `3`, ни `COM3` сюда не подходят. Список можно получить командой `AliceForMarusia-Setup.exe --list-devices`. При настроенном SSH по ключу доступна установка через `--host IP_КОЛОНКИ`.

8. **Дождитесь звука готовности и откройте `http://IP_КОЛОНКИ:100/`** на телефоне в той же сети. IP виден в роутере; установщик также выводит сетевые адреса колонки. Порт 80 помощник не занимает.

9. **При необходимости настройте VPN** во вкладке «VPN»: импортируйте исходную HTTPS-подписку провайдера или поддерживаемую ссылку, затем выберите сервер. Подключение применяется к запросам OpenAI. Если прямой доступ работает, выберите «Напрямую». [Подробнее о настройках](docs/setup.md).

10. **Подключите ChatGPT во вкладке «Диалоги».** Войдите на официальной странице OpenAI. Если на телефоне после входа откроется недоступная страница `127.0.0.1`, скопируйте полный адрес из адресной строки и вставьте в поле «Адрес возврата» на странице колонки. Не передавайте этот адрес другим людям.

11. **Нажмите «Проверить» во вкладке VPN**, затем скажите «Алиса», дождитесь сигнала и задайте вопрос. Обычные команды музыки, таймеров и умного дома продолжайте адресовать Марусе.

12. **Подстройте активацию**, если нужно. В «Настройках» ползунок «Очень часто — Средне — Очень редко». По умолчанию порог 70%; изменения применяются без повторной загрузки модели распознавания. Сдвиг вправо уменьшает ложные срабатывания.

Для Linux/macOS и самостоятельной сборки используйте [установку из исходников](docs/development.md).

## Как пользоваться

- После ответа Алиса продолжает слушать следующую фразу. Две секунды без речи завершают слушание.
- Одно короткое касание панели или повторное «Алиса» отменяет запрос и озвучивание.
- «Следующий диалог», «предыдущий диалог» и «новый диалог» управляют историями. То же доступно в браузере.
- «Не отвечай», «выключись», «замолчи» и похожие команды завершают разговор без записи реплики. Неоднозначные «всё» и «спасибо» работают как отдельные команды.
- Во время обращения звук Маруси временно приглушается. Жёлтое кольцо показывает слушание, обработку и озвучивание.
- Старые неактивные диалоги удаляются после недели, большой контекст сжимается в фоне.

Если нет интернета или аккаунта, Алиса озвучит сохранённую инструкцию. Адрес страницы произносится со словами «точка» и «двоеточие». Для сетевых ошибок есть короткий сигнал.

## Ограничения

Проверена большая Капсула RK3308. Мини требует отдельного порта. GPT и озвучивание используют внешние сервисы; доступность, региональные ограничения и лимиты определяются ими. Поиск разрешён только когда без него нельзя достаточно точно или актуально ответить.

Страница настройки доступна в доверенной домашней сети, без отдельного пароля администратора. Не открывайте её, ADB и SSH в интернет. [Личные данные и доступ](SECURITY.md).
