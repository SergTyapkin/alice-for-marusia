# Сторонние компоненты

Собственный код проекта распространяется по MIT. Лицензии зависимостей сохранены в [third_party/licenses](third_party/licenses), версии и исходные репозитории — в [components.json](third_party/components.json).

| Компонент | Версия / назначение |
| --- | --- |
| CPython | 3.11.18, среда на колонке |
| micro-wakeword / microwakeword-rs | 0.1.3, Linux ARM64 runner; MIT и лицензии TensorFlow microfrontend/KissFFT |
| Sherpa-ONNX | 1.13.8, потоковое распознавание; Apache-2.0 |
| ONNX Runtime | 1.28.2, выполнение STT-модели; MIT |
| Russian Zipformer small Vosk | upstream-пакет 2025-08-16; источник и SHA256 зафиксированы |
| glibc | Debian 2.36-9+deb12u14; LGPL |
| mpg123 | 1.26.4, декодирование MP3; LGPL |
| edge-tts | 7.3.1 и его зависимости; их notices сохраняются в runtime |
| Xray-core | 26.11.9; MPL-2.0, исходный код по ссылке в components.json |
| Android platform-tools | ADB для Windows; notices включены в комплект |

В релизе рядом с бинарниками публикуется архив соответствующих исходников LGPL-компонентов. Они используются как отдельные динамические библиотеки; пользователь может заменить их в runtime. Для внесения изменений в зависимости используйте их исходный код и условия соответствующей лицензии.

Модель слова «Алиса», автор kelstar, доступна в [исходном репозитории](https://github.com/olegchumakov/microwakeword-models). Отдельная лицензия там не указана, поэтому её копия в релиз **не включена**. Установщик получает файл напрямую по закреплённому URL и проверяет SHA256; ссылка находится в `config/wake-model-download.json`.

Стандартные звуковые сигналы генерируются проектом. Пользовательские музыкальные MP3, ключи, диалоги и дампы не публикуются. Озвучивание использует внешний сервис Edge; его доступность и условия определяются провайдером.
