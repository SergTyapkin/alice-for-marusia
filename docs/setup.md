# Настройка Алисы

Откройте `http://IP_КОЛОНКИ:100/` с телефона в той же Wi-Fi сети. Порт 80 остаётся у Маруси. При изоляции Wi-Fi клиентов телефон может не видеть колонку; отключите изоляцию или подключитесь к подходящей сети. Постоянный IP можно закрепить в роутере.

## Аккаунт и диалоги

Во вкладке «Диалоги» нажмите Continue with ChatGPT. Пароль вводится только на официальном сайте OpenAI.

На телефоне после успешного входа адрес `http://127.0.0.1:1455/auth/callback?...` может не открыться. Это ожидаемо: скопируйте весь адрес из адресной строки и вставьте в поле возврата на странице колонки. Завершите вход в течение десяти минут. Для смены аккаунта сначала выйдите из прежнего; выход сам по себе не удаляет историю.

Здесь же можно создавать, выбирать, очищать и удалять голосовые диалоги. Если история изменена из браузера во время ответа, старый ответ не восстановит удалённый диалог.

## VPN

Сначала попробуйте «Напрямую» и нажмите «Проверить». Если OpenAI недоступен, настройте подключение своего провайдера.

- INCY/HAPP: вставьте исходную HTTPS-подписку, получите список и выберите сервер. Название страны берётся из подписи провайдера. Закрытые `happ://` ссылки не подходят — нужен обычный URL подписки.
- VLESS/Trojan: импортируйте полную ссылку с TLS/REALITY и транспортом. Поддерживаются TCP, WebSocket, gRPC и XHTTP в пределах возможностей Xray.
- VMess: base64 JSON share link.
- Shadowsocks: стандартная ссылка без SIP003-плагинов.
- HTTP/SOCKS5: адрес, порт и, при необходимости, логин с паролем.

Импорт обновляет список; для подключения нажмите на нужный сервер. URL подписки не сохраняется. Чтобы обновить список, импортируйте его снова. Приложения INCY/HAPP на колонке не запускаются: их параметры использует Xray. WireGuard и TUN не поддерживаются.

VPN применяется к OpenAI, а не ко всей колонке. Кнопка «Проверить» делает короткий запрос и расходует небольшой лимит аккаунта. Фоновая проверка соединения не гарантирует доступность веб-поиска или другого отдельного инструмента.

## Частота активации

Если Алиса просыпается без обращения, сдвиньте ползунок вправо, в сторону «Очень редко». Если пропускает слово — немного влево. «По умолчанию» возвращает среднее значение. Перезапускается только детектор слова примерно на полсекунды, распознаватель остаётся загруженным.

Технически ползунок меняет порог от 60 до 80 с шагом 1; стандартное значение 70. Это не процент успешно распознанных обращений.
