# Капсула Мини

Готовый установщик рассчитан на большую Капсулу RK3308. Мини использует другую платформу, поэтому установщик намеренно остановится: получение root ещё не делает помощника совместимым.

## Как получить доступ

Для поддерживаемых поздних ревизий Amlogic A113X, платы MRC02B, смотрите раздел Mini в [capsula-jb](https://github.com/librecapsula/capsula-jb#readme). Для них используется короткое окно USB download при подаче питания, а не кнопка Recovery большой колонки. В Windows потребуется WinUSB-драйвер из инструкции соответствующего релиза.

Сначала сделайте бэкап и проверьте манифест и SHA256. Частичные `.partial` не являются полным бэкапом. Не обходите ошибки резервирования параметрами форматирования или `--no-backup`, если не готовы потерять данные.

## Можно ли установить эту Алису

Проверенного готового порта пока нет. Потребуется проверить совместимость библиотек, микрофон, выход звука, ALSA loopback, сенсорную панель, светодиоды и автозапуск. Значения большой Капсулы `hw:7,1`, устройство детектора `2` и LED-каналы 1–39 нельзя переносить без проверки.

Если хотите помочь с портом, начните со сведений о модели, libc, памяти, `pactl list short sources`, `pactl list short sinks`, `/proc/asound/cards`, `/dev/input` и `/sys/class/leds`. Для Alpine также понадобится отдельная служба запуска. Готовый порт лучше оформить отдельным аппаратным профилем и PR с описанием проверенной ревизии.
